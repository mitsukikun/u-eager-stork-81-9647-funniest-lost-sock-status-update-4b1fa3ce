A one-line status update from a lost sock that ended up behind the dryer — its partner escaped, and it has moved on to a new life with a dust bunny. Entry for make.fun's "Funniest Lost Sock Status Update" bounty.

## Run it

```sh
python3 main.py
```

The program writes the status update to `/output/entry.txt`.
